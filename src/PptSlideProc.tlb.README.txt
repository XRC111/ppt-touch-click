// 类型库来源说明
//
// PptSlideProc.TlbGen.dll 是一份只含同名 COM 类（PptTouchClick.SlideWatcher, CLSID 2F4C7A19-...）
// 的桩程序集，只为用 tlbexp.exe / regasm.exe 导出类型库 PptSlideProc.tlb：
//
//   tlbexp.exe src\PptSlideProc.TlbGen.dll /out:dist\PptSlideProc.tlb
//
// 真正的实现是 src\SlideWatcher.cpp，编译成 PptSlideProc.x64.dll / PptSlideProc.ocx；
// 它们的 DllRegisterServer 会把资源里的这个 .tlb 写到同目录并注册。
// 桩程序集和真实实现的 ProgID / CLSID 一致，因此类型库可被直接复用。
